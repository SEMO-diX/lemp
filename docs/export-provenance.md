# Export provenance

The public repository was created as a clean repository rather than by changing the visibility of the private development-memory repository.

The protocol baseline used to start this implementation was the validated private checkpoint **CP000028** on 2026-09-29.

Only protocol/implementation concepts were exported. Real sessions, events, source-recovery archives, current state, and private Git history were excluded.

The public implementation is expected to diverge structurally from the private memory instance as it becomes a reusable product.
